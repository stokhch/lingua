# Референсы: open-source проекты для изучения языков

Поиск по GitHub (ноябрь 2026). Звёзды — на момент поиска.

| Проект | ⭐ | Лицензия | Что это | Что взяли в Лингву |
|---|---|---|---|---|
| [ankitects/anki](https://github.com/ankitects/anki) | 33k | AGPL-3.0 (большая часть) | Эталонные карточки с интервальным повторением | Идея карточек с 4 оценками («Не помню / Трудно / Помню / Легко») и показом интервала на кнопке. Код не копировался. |
| [kantord/LibreLingo](https://github.com/kantord/LibreLingo) | 2.6k | AGPL-3.0 | Открытая платформа курсов в духе Duolingo | Подход «курс → уроки → упражнения с проверкой» для раздела грамматики. Код не копировался. |
| [LuteOrg/lute-v3](https://github.com/LuteOrg/lute-v3) | 1.6k | MIT | Чтение текстов: клик по слову → перевод, статусы слов | Механика ридера: подсветка слов по статусу, добавление слова с предложением-контекстом. |
| [simjanos-dev/LinguaCafe](https://github.com/simjanos-dev/LinguaCafe) | 1.5k | GPL-3.0 | Самостоятельно размещаемый ридер + словарь + повторения | Связка «тексты → личный словарь → повторения». Код не копировался. |
| [open-spaced-repetition/ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) | 0.9k | MIT | Современный алгоритм повторений FSRS на TypeScript | Рассматривался как планировщик; в проекте пока свой SM-2 (`public/js/srs.js`) — FSRS можно подключить как замену. |
| [sanidhyy/duolingo-clone](https://github.com/sanidhyy/duolingo-clone) | 0.7k | MIT | Клон Duolingo на Next.js | Геймификация: XP, дневная цель, стрик. |
| [bryanjenningz/react-duolingo](https://github.com/bryanjenningz/react-duolingo) | 0.5k | MIT | Клон Duolingo на React | Вид экранов упражнений и обратной связи. |
| [FreeLanguageTools/vocabsieve](https://github.com/FreeLanguageTools/vocabsieve) | 0.6k | GPL-3.0 | «Добыча» предложений для карточек | Сохранение контекста вместе со словом. |
| [fasiha/ebisu](https://github.com/fasiha/ebisu) | 0.3k | Unlicense | Байесовский планировщик повторений | Альтернатива SM-2 на будущее. |

Итог: весь код Лингвы написан с нуля, сторонний код не включён, поэтому ограничений GPL/AGPL нет. Проект распространяется под MIT.
Название, маскот (ёжик Пим), тексты, словарь и упражнения — оригинальные; бренд, тексты и графика lingualeo.com не использовались.
